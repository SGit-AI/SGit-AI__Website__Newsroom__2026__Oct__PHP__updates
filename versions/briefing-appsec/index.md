# Briefing for a head of appsec: Which of our applications are in scope, which settings matter, and what do we add to the pipeline? The php2shell story for a head of appsec: what to decide, the claims it rests on with their status and sources, and what is still open. Briefing · Head of AppSec # Which of our applications are in scope, which settings matter, and what do we add to the pipeline? Scope, settings and the pipeline change. The bug is below your applications: any PHP endpoint that reaches the runtime is a candidate, and the demonstrated paths run before application code. ## What to decide or do - In scope: every application on an affected runtime, including the ones with no uploads and no sessions; the session upload-progress path is on by default and needs no session_start(). - Settings that bound the known paths, in the order of least breakage: session.upload_progress.enabled=0 (server-level, not ini_set); post_max_size low; max_input_nesting_level low; max_multipart_body_parts on patched builds; fatal_error_backtraces=0 on 8.5; pm.max_requests on FPM. None is a fix. - The runtime version in production is now an application-security finding: add it to the SBOM, fail the pipeline on an unfixed PHP, and check the running version after deploy, not the package version before. - Detection belongs at the edge and on the host, not in the app: the request shape (upload-progress field plus many array parts, oversized multipart bodies) and the process tree (a worker spawning a shell). - The public proof-of-concept code does not work as published, per VulnCheck and a lab reproduction; a scanner that fires on it is testing the wrong thing. ## The facts this rests on - confirmed two or more primary sources agree, or the fact was counted from a captured file - reported one party says so, and it has not been contradicted - disputed the sources disagree, and both readings are shown - contradicted a primary source says otherwise - unverified even the reporting outlet could not check it - p/n primary sources among the n cited;
